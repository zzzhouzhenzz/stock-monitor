## Design Context

### Users
The owner is an experienced engineer reviewing the stock monitor across macOS
and Linux. The primary page answers which function calls which other function.
A separate files and definitions page preserves repository containment.

### Brand Personality
Precise, calm, and tactile. Use the owner's preference for polished creative
modernism, with clear technical descriptions and no promotional copy.

### Aesthetic Direction
A caller-to-callee diagram with subtle layer depth on a warm light background.
Keep the selected function between its callers and callees. Use clear code
identifiers, directional arrows, source evidence, and restrained motion. The
call relationships are the main content; folder containment belongs in the
secondary hierarchy view.

### Design Principles
- Make real caller-to-callee relationships inspectable, with exact call sites.
- Derive call edges from Python source and label verified dynamic bindings.
- Distinguish calls from containment, data flow, and possible execution order.
- Show the limits of static analysis and the omitted calls for each function.
- Use layer depth to clarify relationships while keeping labels easy to read.
- Respect reduced motion and keep all controls available on smaller screens.
- Keep credentials and live account data out of both documentation pages.
