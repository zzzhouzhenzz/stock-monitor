## Design Context

### Users
The owner is an experienced engineer reviewing the stock monitor across macOS
and Linux. This page shows actual repository containment through a 3D hierarchy:
directories, files, classes, functions, methods, and nested definitions.

### Brand Personality
Precise, calm, and tactile. Use the owner's preference for polished creative
modernism, with clear technical descriptions and no promotional copy.

### Aesthetic Direction
A connected code tree with subtle 3D depth on a warm light background.
Use clear code identifiers, fine rules, and restrained motion. The code tree is
the main content; responsibility groups must not replace the real hierarchy.

### Design Principles
- Make the real code structure inspectable, with source links.
- Derive parent-child relationships from the filesystem and Python syntax tree.
- Keep the 3D effect useful; provide flat and outline views with keyboard controls.
- Respect reduced motion and keep all controls available on smaller screens.
- Keep credentials and live account data out of this documentation page.
