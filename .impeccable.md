## Design Context

### Users
The owner is an experienced engineer reviewing the stock monitor across macOS
and Linux. This page explains the files and runtime flow through a 3D hierarchy.

### Brand Personality
Precise, calm, and tactile. Use the owner's preference for polished creative
modernism, with clear technical descriptions and no promotional copy.

### Aesthetic Direction
An architectural model with colored planes on a warm light background. This is
the initial default; a dark background was offered as an optional preference.
Use large editorial type, fine rules, and restrained motion.

### Design Principles
- Make the real code structure inspectable, with source links.
- Distinguish responsibility groups from runtime call order.
- Keep the 3D effect useful; provide a flat view and keyboard controls.
- Respect reduced motion and keep all controls available on smaller screens.
- Keep credentials and live account data out of this documentation page.
